# Getting Help

Before opening a support request:

1. Read the [README](README.md) and setup instructions.
2. Search existing issues for the same problem.
3. Confirm that dependencies are installed with `flutter pub get`.
4. Run `flutter doctor -v` and `flutter analyze`.

When reporting a problem, include:

- Operating system and version.
- Flutter and Dart versions (`flutter --version`).
- Device or emulator details.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Relevant error output with secrets and personal information removed.

Use GitHub Issues for reproducible bugs and feature requests. Do not post passwords, API tokens, Firebase service-account files, private user data, or proprietary datasets.
